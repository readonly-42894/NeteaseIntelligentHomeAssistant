# 统一响应结构

> 本文属于 [API 工作原理](../API工作原理.md) 的「统一响应结构」部分。

所有接口返回 `ResponseWrapper<T>`：

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | int | **0 表示成功**，非 0 为错误 |
| `errorMsg` | string | 错误信息 |
| `result` | T | 业务数据 |
| `showType` | int | 展示类型 |
| `alertInfo` | FlyAlertItem | 弹窗信息 |
| `rawResult` | object | 原始结果 |

列表接口返回 `ListResponse<T>`：

```
{ "list": [T...], "page": PageInfo{ pageCnt, pageIndex, pageSize, totalCnt } }
```

在 [`openapi.yaml`](../openapi.yaml) 中，每个端点的响应 schema 都已按 `ResponseWrapper<T>`（列表再套一层 `ResponseWrapper<ListResponse<T>>`）包装。
